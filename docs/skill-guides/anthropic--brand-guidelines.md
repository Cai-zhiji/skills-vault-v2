# brand-guidelines

> 把 Anthropic 官方品牌色与字体应用到任意产物，保证品牌视觉一致。

## 1. 一句话理解

`brand-guidelines` 是一份**品牌规范**：Anthropic 的官方配色（`#141413`、`#faf9f5`、`#d97757` 等）与字体（如 Styrene 系列），用于给任何需要 Anthropic 视觉的产物套上正确的观感。

## 2. 它解决什么问题

需要"看起来像 Anthropic 官方出品"的产物（幻灯片、文档、图、页面）时，靠记忆取色/取字会偏。本 skill 把官方色板、字体、字重、用法规则集中起来，保证一致。

## 3. 核心心智模型

**约束型规范。** 内容组织成 12 个章节：品牌风格总览、能力概览、Brand Guidelines、Colors（具体色值）、Typography、Features、Smart Font Application、Text Styling、Shape and Accent Colors、Technical Details、Font Management、Color Application。使用时应把它当**决策入口**，按其中指向的文件（`LICENSE.txt`）补足许可与字体管理规则。

## 4. 一次典型运转

要做 Anthropic 风格产物 → 读 Colors/Typography 章节取官方色值与字体 → 按 Text Styling / Shape / Color Application 应用 → 核对 Font Management 与许可。

## 5. 何时用 / 何时不用

**用**：品牌色、样式指南、视觉格式、公司设计标准相关。

**不用**：不需要 Anthropic 品牌观感的通用设计。

## 6. 依赖与网络位置

- 附属 `LICENSE.txt`（字体/素材许可）。
- 是 `anthropic` 来源的品牌规范。

## 7. 易错点与坑

- **凭记忆取色**：用官方色值（如 `#141413` 背景、`#d97757` 强调），别近似。
- **忽略字体许可**：字体重分布/修改受 `LICENSE.txt` 约束。
