# xlsx (academic)

> 电子表格全流程：创建、读取、编辑、修复 `.xlsx`/`.xlsm`/`.csv`/`.tsv`，公式、格式化、图表、清洗杂乱数据。

## 1. 一句话理解

`xlsx` 是**电子表格的主入口**：只要 `.xlsx`/`.xlsm`/`.csv`/`.tsv` 是主要输入或输出——增列、算公式、格式化、画图、清洗脏数据、格式转换——就归它。

## 2. 它解决什么问题

表格数据是科研和办公的高频格式，但公式错误、格式不规范、脏数据（错行、错位表头）很常见。本 skill 给出创建/编辑/清洗/转换的规范，尤其财务模型的行业配色与数字格式标准。

## 3. 核心心智模型

**交付物必须是电子表格文件。** 一个核心触发边界：主要交付物是 Word/HTML 报告/独立 Python 脚本/数据库 pipeline/Google Sheets API 集成时**不触发**，哪怕涉及表格数据。

**输出硬要求**：统一专业字体（Arial/Times New Roman）；**零公式错误**（`#REF!`/`#DIV/0!`/`#VALUE!`/`#N/A`/`#NAME?` 一个都不能有）；更新模板时精确匹配已有格式（**模板约定永远优先于这些指南**）。

**财务模型配色/格式**：蓝字=硬编码输入、黑字=公式、绿字=同簿跨表引用、红字=跨文件外链、黄底=需注意的关键假设；年份格式为文本（"2024" 而非 "2,024"）。

## 4. 一次典型运转

打开/创建 → 增列算公式 → 按规范格式化（财务模型用配色标准）→ 图表 → 清洗脏数据 → 校验零公式错误 → 转换格式。

## 5. 何时用 / 何时不用

**用**：开/读/改/修 `.xlsx`/`.xlsm`/`.csv`/`.tsv`、建新表、格式转换、清洗脏表格数据。

**不用**：主要交付是 Word/HTML/Python 脚本/DB pipeline/Google Sheets API（哪怕有表格数据）。

## 7. 易错点与坑

- **交付公式错误**：零公式错误是硬要求。
- **覆盖模板既有格式**：更新模板时精确匹配，别强加标准格式。
- **年份被当成数字**：年份用文本字符串。
