# canvas-design

> 用设计哲学创作 `.png`/`.pdf` 静态视觉作品（海报、艺术图），强调原创、不复制现有艺术家。

## 1. 一句话理解

`canvas-design` 是**静态视觉版的生成艺术**：先写一份"视觉哲学"（设计美学运动），再把它**表达在画布上**（`.pdf` 或 `.png`），产出 90% 视觉设计 + 10% 必要文字的作品。

## 2. 它解决什么问题

做海报、艺术图、静态设计时，直接画容易得到模板化结果。本 skill 和 `algorithmic-art` 同构，但面向**静态视觉**（形式、空间、色彩、构图），先逼出原创美学运动，再落成作品。

## 3. 核心心智模型

**视觉哲学先行。** 两阶段：

1. **设计哲学创作**（`.md`）：给运动起名（1–2 词，如 "Brutalist Joy"），4–6 段写清它如何通过空间与形式、色彩与材料、构图体现。
2. **画布表达**（`.pdf`/`.png`）：同一版本把哲学表达成 90% 视觉设计 + 10% 必要文字。

**批判性理解**：用户输入是地基而非约束；强调视觉表达、空间沟通、艺术诠释、最少文字。

## 4. 一次典型运转

1. 读用户输入（作灵感，不约束）。
2. 写视觉哲学 `.md`：命名 + 宣言。
3. 在画布上表达成 `.pdf`/`.png`，90% 视觉 + 10% 文字。

## 5. 何时用 / 何时不用

**用**：用户要海报、艺术图、设计、静态作品。

**不用**：动态/交互/代码生成艺术（`algorithmic-art`）；复制现有艺术家作品（明确禁止）。

## 6. 依赖与网络位置

- 与 `algorithmic-art` 是"静态视觉"vs"代码生成"的孪生。
- 是 `anthropic` 来源的视觉创作技能之一。

## 7. 易错点与坑

- **跳过哲学直接画**：退回模板化结果。
- **复制艺术家作品**：必须原创。
- **文字太多**：视觉为主，最少文字。
