# simpy

> 进程式离散事件仿真：队列、资源、时间事件，用 Python 生成器建模系统。

## 1. 一句话理解

`simpy` 是**离散事件仿真框架**：用 Python 生成器函数建模进程，让实体（顾客/车辆/数据包）随时间互动、竞争共享资源（服务器/机器/带宽）。

## 2. 它解决什么问题

制造系统、服务运营、网络流量、物流、容量规划这类"实体竞争共享资源"的系统，需要仿真来验证行为和优化资源。`simpy` 用纯 Python 进程 + 事件驱动调度做到。

## 3. 核心心智模型

**进程（生成器）+ 资源 + 事件。** 核心能力：用 Python 生成器函数建模进程；共享资源管理（服务器/容器/仓库）；事件驱动调度与同步；可同步墙钟的实时仿真；监控与数据采集。

**资源使用模式**：`Environment`（仿真环境）→ `process`（启动进程）→ `Resource`（竞争的资源）→ `run`（推进时间）。

## 4. 一次典型运转

建 `Environment` → 定义进程函数（`yield` 请求资源/等待时间）→ 启动进程 → `env.run()` → 采集队列/吞吐数据。

## 5. 何时用 / 何时不用

**用**：离散事件系统、资源竞争、队列分析（等待时间/服务时间/吞吐）、制造/物流/服务过程优化、网络仿真（包路由/带宽/延迟）、容量规划、系统验证。

**不用**：固定时间步的连续仿真（用 SciPy ODE 求解器）；无资源共享的独立进程。

## 6. 依赖与网络位置

- 是 `scientific-toolkit-skill` 的 embedded 子技能。

## 7. 易错点与坑

- **拿它做连续仿真**：固定时间步的连续系统用 ODE，不是 SimPy。
- **进程忘了 yield**：SimPy 进程是生成器，资源请求/等待必须 `yield`，否则不会"耗时"。
