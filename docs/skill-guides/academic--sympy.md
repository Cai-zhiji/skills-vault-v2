# sympy

> Python 符号数学：代数求解、微积分、表达式化简、符号矩阵、物理、数论、几何、代码生成。

## 1. 一句话理解

`sympy` 做**符号计算**：用符号而非数值近似做精确计算——解方程、求导积分、化简表达式、符号矩阵、物理、数论、几何，还能把表达式转成可执行代码（Python/C/Fortran）。

## 2. 它解决什么问题

当需要**精确结果**（`sqrt(2)` 而不是 `1.414…`）或处理带变量/参数的公式时，数值库给不了。`sympy` 用符号运算给出精确、可推导的结果。

## 3. 核心心智模型

**符号优先。** 创建符号（`symbols('x y')`）→ 建表达式 → 代数操作。能力分块：符号计算基础（带假设的符号）、微积分（导数/积分/极限/级数）、方程求解（代数/微分/方程组）、符号矩阵与线性代数、物理与力学、数论（素数/因式分解/模运算）、几何（2D/3D）、代码生成（转 Python/C/Fortran）、LaTeX 输出。

## 4. 一次典型运转

定义符号 → 建表达式 → 求导/积分/解方程 → 化简 → 转成 LaTeX 或可执行代码。

## 5. 何时用 / 何时不用

**用**：符号解方程、微积分、表达式化简、符号矩阵、物理计算、数论、几何、代码生成、需要精确结果（含变量/参数的公式）。

**不用**：纯数值近似（用 NumPy/SciPy 更快）。

## 6. 依赖与网络位置

## 7. 易错点与坑

- **符号和数值混用**：符号计算慢，纯数值场景别硬用 sympy。
- **忘给符号加假设**：正数/实数等假设会影响化简与解的合法性。
