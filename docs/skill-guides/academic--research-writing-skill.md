# research-writing-skill

> 中文优先的科研论文写作：撰写、修改、润色、分节起草、回复审稿、毕业论文润色、稿件论证规划。

## 1. 一句话理解

`research-writing-skill` 负责**论文正文这一件事**：只要交付物是 prose / LaTeX / Markdown / 稿件文本，就归它。它不碰 Word/PPT（那是 `office-academic-skill`），也不碰 MATLAB/Python/绘图（那是 `scientific-toolkit-skill`）。

## 2. 它解决什么问题

论文写作最怕两件事：一是**编数据**（DOI、期刊、实验设置、结果），二是**空洞**（"显著、先进、有效、鲁棒"这类没有度量的话）。本 skill 用证据标签和"可验证技术陈述优先"把这两件根治，并给每个章节一套默认写作动作。

## 3. 核心心智模型

**四类来源分离**：`原文/已有数据` / `用户确认内容` / `根据上下文推断` / `建议性扩展`。定量主张和文献主张都要贴证据标签。

**空洞词替换**：把"显著/先进/有效/鲁棒"换成**带度量的条件**（和什么基线比、在什么条件下）或直接删掉。

**论证先于行文**：写全篇前先建 argument outline（问题→缺口→方法→证据→贡献→局限），再写连贯段落，不写空口号式 bullet。

## 4. 一次典型运转

起草一个新章节：

1. 澄清目标（期刊/会议/论文/课程、语言、长度、读者、格式）。
2. 识别素材（论文笔记、实验数据、图、表、MATLAB/Python 输出、参考文献、导师意见）。
3. 建论证大纲。
4. 用连贯段落起草（非空 bullet）。
5. 给定量/文献主张加来源标签。
6. 修订：逻辑、具体性、术语一致、引用准确。

**分节默认动作**：摘要（问题/方法/实验/关键结果/贡献）、引言（背景/未解缺口/为何重要/方案/贡献）、相关工作（按技术主题组织、比较假设与局限，别一篇篇流水账）、方法（模型假设/变量/流程/算法/可复现细节）、实验（数据/平台/参数/指标/基线/重复/可视化）、结果讨论（先主张后证据再机制最后局限）、结论（回答问题/总结证据/局限与下一步）。

## 5. 何时用 / 何时不用

**用**：写/改论文正文、摘要、引言、方法、结果、讨论、结论、相关工作、审稿回复、LaTeX/Overleaf 文本、学术 prose。

**不用**：Word/PPT 交付物（`office-academic-skill`）；MATLAB/Python/绘图/统计/仿真/文献检索（`scientific-toolkit-skill`）。

## 6. 依赖与网络位置

- 附属：`references/paper-writing/`（brainstorming_guide、section_rhetorical_moves、writing_checklists、figure_templates、author_profile）——来自外部 systems/networking 仓库，当作可选 craft 参考、非硬规则，并适配光电信息科学。
- 与另两个学术 skill 三足分工。

## 7. 易错点与坑

- **编数据/DOI/期刊/结果**：明确禁止。
- **空洞词**：用度量条件替换或删除"显著/先进/有效/鲁棒"。
- **逐篇流水账写相关工作**：要按技术主题组织、比较假设与局限。
- **修订时改用户本意**：除非确需改动，保留用户的意图与术语。
