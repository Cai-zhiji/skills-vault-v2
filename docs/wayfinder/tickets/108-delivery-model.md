# 确定本地交付与升级方式

- 状态：已决定
- 类型：Research
- 阻塞：选择运行时与进程边界、制定旧项目数据迁移方案
- 解锁：发布与运维任务拆分

## Decision question

用户如何安装、启动、后台运行、升级和排查 Skills Vault v2？

## Topics

- 开发模式与日常使用模式是否使用同一启动入口。
- macOS launchd 是否继续支持，是否扩展其他平台。
- 静态前端产物如何随本地服务分发。
- 旧数据迁移的首次启动流程与回退。
- 日志、健康检查和诊断包的用户入口。

## Resolution

- 开发：Python API 使用 8766，Vite 使用 5173 并代理 `/api`。
- 日常使用：先构建 `app/dist`，再由 `scripts/vault-ui` 在 127.0.0.1:8765 提供单端口应用。
- 数据目录通过参数或环境变量配置，启动时输出实际路径。
- 首版支持 macOS/Linux 的本地前台启动；launchd 后台服务作为后续运维增强，不阻塞产品可用。
- 不自动 push、发布或设置系统后台项。
