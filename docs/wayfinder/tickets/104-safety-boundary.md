# 确定安全事务与权限边界

- 状态：待决定
- 类型：Grilling
- 阻塞：无
- 解锁：确定 API 与异步操作契约、确定测试接缝与验收矩阵

## Decision question

哪些操作必须预览、确认、备份和记录，哪些只读或可重建操作可以直接执行？

## Known constraints

- 安装、更新、删除、来源策略与恢复会改变本地状态。
- 扫描主要重建 Catalog，但仍可能覆盖生成文件。
- 来源中的本地改动不得被自动删除、stash、commit 或覆盖。
- 一次性 preview token 与状态指纹是旧系统已验证的安全基础。

## Decisions to make

- 操作风险分级与一致的 UI 容器。
- token 生命周期、重复消费、过期与重新检查语义。
- 批量操作中的部分可执行与原子回滚策略。
- 后端允许访问的路径与拒绝越界规则。
- 备份保留、恢复范围和用户级目录保护名单。
