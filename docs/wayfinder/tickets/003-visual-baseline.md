# 确定视觉基线

- 状态：已决定
- 类型：Prototype

## Decision question

如何从参考资料中形成属于 Skills Vault 的界面语言？

## Resolution

采用“本地仓库工作台”方向：冷铝灰工作面、石墨文字、克制的铜色主动作与语义状态色；使用紧凑数据行、细分隔线和清晰路径信息。签名元素是“本地文件 → Catalog → Codex / Claude Code”同步轨。

Linear 只提供信息密度与克制层级参考，Raycast 只提供快捷搜索与命令入口参考，Vercel 只提供技术信息可读性参考。项目不复制这些品牌的深色营销页面、品牌色或专有字体。

## Rationale

Skill 管理的真实对象是文件、来源、索引、平台链接和事务。同步轨直接编码这些关系，比通用统计卡片或营销式 hero 更能建立项目身份。
